## AI 简历优化

面向 AI Agent、LLM 应用和后端工程项目经历，以技术面试官视角梳理业务背景、个人贡献与工程细节，帮助把真实经历写得清楚、自然，并能经得起面试追问。

- **先讲清为什么做**：优先按照“具体问题或约束 → 个人动作 → 关键机制 → 已知结果或验证方式”组织贡献，避免先堆技术名词、最后才解释用途。
- **保留真实经历**：区分原文事实、岗位 JD 和待核实信息，保留个人与团队职责边界，不补造技术、背景、指标或成果。
- **支持按需输出**：默认提供原简历锐评、优化后的项目经历、修改说明与面试风险；也可以指定只要成稿或只做锐评。
- **支持岗位对齐与补充更正**：根据 JD 调整已有亮点的顺序，使用后续补充、更正的事实，并将核实问题放在简历正文之外。

使用时提供项目经历原文；目标岗位或 JD 可选。安装后可在 Codex 中调用：

```text
$resume-agent-optimizer 帮我优化下面的项目经历，先讲清具体问题，再写个人动作、技术机制和已有结果。
```

如果只需要改写后的正文：

```text
$resume-agent-optimizer 根据下面的岗位 JD 优化这段项目经历，只输出简历正文。
```
