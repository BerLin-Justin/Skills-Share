# 图解交付回归记录

本记录仅供维护 Skill。检查日期 2026-11-13，不能据此宣称全部业务用例、原系统或所有阅读器通过。

## 实际观察

- 用户反馈的旧交付约 3.3 万字符，主体为长文，只有一张新 Mermaid 关系图，插入的图片为原文截图，缺少独立数据流转、时序和技术架构图。旧主规则、模板和界面提示词都偏向文字完整、图示辅助。
- 无新版 Skill 的独立样本产生四类 Mermaid 源，但没有渲染图片；仅有图种和代码围栏仍达不到交付要求。
- 新版完整链路样本初稿由独立执行生成。维护者实际渲染并发现中文越框、单图过长和外部付款边界不够明确，随后修正字体度量、拆图及候选标记；最终示例为九张渲染图，覆盖四类视角，含逐单归属、当前值／快照、拒绝／驳回、重复事件及核销边界。
- 小查询独立样本保留真实夹具的 Python／SQLite、权限与分页语义，只用一张改动图，没有强行展开四图和排期。图由修正后的渲染器重新生成并查看。

## 渲染回归

实际曾复现：中文字形约 233pt，节点只有 191.5pt，文件生成成功但文字超框。现在先使用实际中文字形测量，再布局并恢复原文字体；不是缩小字体隐藏问题。

以下四项 CLI 测试均已执行通过：

1. 中文长标签在节点内，并恢复真实字体。
2. 输出包含真实中文的 SVG 与可读 PNG。
3. 批量输入中有错误图时，发布前整批失败。
4. 默认保护已有文件，只有显式 overwrite 才重绘。

命令：以已有 Node 执行 `--test evals/render-diagrams.test.mjs`；`PRD_DIAGRAM_MODULES` 指向已有的 node_modules。无需联网安装。此处不硬编码会随宿主升级变化的依赖路径。

## 人工核对范围

已逐张查看完整链路九图和小查询一图，检查中文、框内文字、连线、分支、参与者、候选标签与正文引用。密图按阶段拆分，检查约 1100px 文档宽度下的可读性；源、SVG、PNG 同步保留。
