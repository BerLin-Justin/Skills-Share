# 本人工单查询：开发顺序清单

配套：[需求图解](example-confirmed-handoff.md) · [关键接口契约](example-confirmed-contract.md)。仅覆盖新增可选状态筛选；无实际开发完成证据，以下均未勾选。完成后将 `- [ ]` 改为 `- [x]`，可追加负责人、日期及实现／验证记录。以下顺序供核对，真实前端与HTTP适配文件仍需定位。

## 先核对 再分端实现

- [ ] **T01 核对现有查询及适配层**。依赖：无。完成：核对handle_list_tickets、list_tickets及既有协议，定位真实页面和HTTP适配文件，记录复用点。关联：分析开发改动、契约T01。
- [ ] **T02 状态筛选交互**（前端）。依赖：T01。完成：选择、切换、清除状态正确透传，切换或清除时游标归零，错误结果与空结果区别显示。关联：分析图、契约T01。
- [ ] **T03 参数透传与兼容校验**（后端）。依赖：T01。完成：可选状态按约束校验后透传，原调用省略时保持旧行为，身份仍来自可信登录。关联：契约T01输入及失败。
- [ ] **T04 状态与权限在分页前过滤**（后端）。依赖：T01。完成：在既有单表查询添加参数化条件，权限、游标、稳定排序及历史null语义保持。关联：分析复用查询链。
- [ ] **T05 适配层接入与错误结果**（后端）。依赖：T03、T04。完成：真实GET入口接通新参数，响应信封、错误码及空结果符合原契约，查询异常不伪装空数组。关联：契约T01。

T02与T03／T04在T01完成后可并行，T03与T04最终经T05合并验证。

## 关键验证与交付

- [ ] **T06 前后端关键边界联调**（前后端／测试）。依赖：T02、T05。完成：验证省略／合法／非法状态、历史null、他人不可见、分页前过滤、切换游标及查询异常，记录实际结果。关联：分析关键验收。
- [ ] **T07 检查查询访问路径**（后端）。依赖：T04。完成：代表数据下查看有／无状态过滤的执行计划、扫描量及IO，再决定是否调整索引，留下依据。关联：分析权限与性能。
- [ ] **T08 核对交付及文档同版**（研发／测试）。依赖：T06、T07。完成：原调用兼容，关键验证记录可查，分析、契约、清单与实现一致，保留各任务进度。关联：需求图解、契约T01。

该示例不等于功能、接口或性能已验证，不将静态阅读夹具标为开发完成。后续更新保留任务ID、已确认的勾选及备注；需求变更影响已完成项时说明需复核之处。
